# Contributing blueprints

Use the blueprint-submission issue form for proposals. A submission must:

- conform to `schema/policy-pack.schema.json`;
- describe reusable architectural boundaries rather than one repository;
- explain appropriate and inappropriate use;
- name its layers and target stack;
- use supported rule kinds for every enforcing rule; and
- contain no code, repository names, web addresses, or project-specific evidence.

Maintainers may refine a proposal while implementing it in the Shore Guard source repository. A proposal becomes a shipped preset only after its implementation, tests, documentation, and stable content hash pass the Shore Guard release gates. Exported files in this catalog are generated; changes to them without a corresponding shipped preset are not accepted.
